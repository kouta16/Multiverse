# مالتيفرس — نسخة الاستضافة (دايماً شغالة)

فيه هنا كل ملفات اللعبة + السيرفر. اتبع خطوة واحدة بس من الاتنين تحت،
وفـ اللعبة تتفتح لأي حد في أي وقت + لينك ثابت ومجاني ومميز.

ملاحظة مهمة: الاستضافة المجانية بتوقف اللعبة لو مفيهاش زوار شوية
(تنام)، وأول واحد يحاول يفتحها بياخد 30-60 ثانية عشان تصحى (بيشوف
صفحة انتظار). بعدها بتمشي عادي.

---

## الطريقة (أ): Glitch — الأسهل، من غير GitHub

1. سجل حساب مجاني في https://glitch.com
2. ارفع ملف `multiverse-live.zip` ده في مشروع جديد:
   - ادفع على **New Project** واختار أي مشروع جاهز (مثل hello-express).
3. في المحرر على الشمال اضغط على **assets** + اسحب `multiverse-live.zip` هناك.
   - اضغط على الملف بعد الرفع وانسخ **Copy Url**.
4. افتح **Settings** ← **Advanced Options** ← **Open Console**.
5. في الطرفية (الكونسول) اكتب بالترتيب:
   ```
   wget -O app.zip <حط رابط الملف اللي نسخته>
   unzip app.zip -d .
   rm app.zip
   refresh
   ```
6. اللينك بتاعك الثابت: `https://اسم-المشروع.glitch.me`

---

## الطريقة (ب): Render — أنضف، محتاج GitHub

1. اعمل حساب مجاني في https://github.com وارفع محتوى الـ folder ده فيه
   (server/ و public/ و package.json و render.yaml).
2. سجل في https://render.com واربط حساب GitHub.
3. اضغط **New** ← **Web Service** ← اختار الريبو.
   (ملف `render.yaml` موجود — هيقراه ويظبط البناء تلقائياً؛ لو لا:
   Build Command = `npm install` ، Start Command = `node server/index.js` ،
   واختار **Free**).
4. اللينك بتاعك الثابت: `https://اسم-الخدمة.onrender.com`

---

## ملحوظات

- الحسابات والكوينز بتتحفظ في `server/data/users.json`. على Glitch بتفضل
  موجودة، على Render المجاني لا (المخزن بيتنضف لما اللعبة تنام).
- الرومات بتمسح لو الكل خرج والاستضافة نايمة — طبيعي للاستضافة المجانية.
- عشان تحدّث اللعبة بعد كده: غيّر الملفات وارفع تاني (Glitch = ارفع الصور تاني
  أو عدل من المحرر، Render = push على GitHub وده يـ deploy تلقائياً).
